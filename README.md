This project shows an example of a patient overview which is used by hospital personnel of in this case the Psychiatric Division. 
It is a simplified version to show a base application.
A staff member can log in with their email and password, if filled in incorrectly an message will appear based on the incorrect input.

 Role-based authorization is used to give/deny access to certain information.
   ex. a nurse does not have access to edit the medication of a patient only a doctor does.
The patient overview is a simple table with CRUD functionalities. When a patient is "deleted", their information is saved in the history of hospitalizations.
